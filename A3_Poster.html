NEVS (National Employment Verification System) :

A Blockchain-Based Enterprise Solution

Brief Description:

NEVS (National Employment Verification System) is a production-ready enterprise blockchain platform designed to establish trust and accountability in digital hiring ecosystems. Inspired by real-world concerns around fraudulent job postings and misuse of candidate data, the system provides a secure, multi-organization framework for creating and verifying employment records through mutual consent and cryptographic validation. The backend is built using Node.js and Express 4, integrated via the Fabric Network Gateway, while smart contracts (Chaincode) are written in Go using the Chaincode as a Service (CCaaS) architecture. It incorporates dual-endorsement policies, dynamic service discovery, and Private Data Collections (PDC) to ensure data integrity, privacy, and tamper-proof verification.

Principle:

The platform leverages Enterprise Blockchain Technology—specifically Hyperledger Fabric—to build a decentralized trust layer for employment verification. It enforces a dual-consent model where both employer and candidate participation are required to validate any employment record, eliminating the possibility of unilateral or fraudulent entries. Using a Raft consensus mechanism and strict dual-endorsement policy, every transaction is cryptographically signed by independent organizations (CentralGovt and CompanyOrg) before being committed. Additionally, Private Data Collections (PDC) ensure that sensitive information such as salaries remains confidential through transient data routing over mTLS, enabling regulatory compliance while preserving privacy and data ownership.
