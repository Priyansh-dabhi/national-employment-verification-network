<!-- ═══════════════════ BRIEF DESCRIPTION ═══════════════════ -->
<h3 style="color: #1e3a8a; margin: 0 0 8px 0; font-size: 16px; font-weight: 700; border-bottom: 2px solid #3b82f6; display: inline-block; padding-bottom: 3px;">Brief Description:</h3>
<p style="margin: 0 0 20px 0; text-align: justify; font-size: 14px; line-height: 1.6; color: #334155;">
<strong>NEVS (National Employment Verification System)</strong> is a robust, production-ready enterprise blockchain solution built on Hyperledger Fabric. The platform offers a highly secure, multi-organization framework for recording and verifying employment records while ensuring strict cross-organizational consensus. The backend is built using Node.js and Express 4, connected via the Fabric Network Gateway, while the smart contracts (Chaincode) are written in Go leveraging the Chaincode as a Service (CCaaS) architecture. It features a dual-endorsement policy, dynamic service discovery, and built-in Private Data Collections (PDC) to guarantee data integrity, immutability, and enterprise-grade access control for sensitive data.
</p>

<!-- ═══════════════════ PRINCIPLE ═══════════════════ -->
<h3 style="color: #1e3a8a; margin: 0 0 8px 0; font-size: 16px; font-weight: 700; border-bottom: 2px solid #3b82f6; display: inline-block; padding-bottom: 3px;">Principle:</h3>
<p style="margin: 0 0 20px 0; text-align: justify; font-size: 14px; line-height: 1.6; color: #334155;">
The platform employs Enterprise Blockchain Technology—specifically Hyperledger Fabric—to deliver a decentralized and cryptographically secure ledger for verifying employment history. It uses a Raft consensus orderer alongside a strict dual-endorsement policy, requiring digital signatures from two independent network organizations (CentralGovt and CompanyOrg) before committing any state change. Additionally, Private Data Collections (PDC) are utilized via transient data routing over mTLS to completely isolate and secure highly sensitive attributes, such as salaries and compensation. This ensures that sensitive information is completely hidden from unauthorized peers and ordering nodes, achieving perfect regulatory compliance and data privacy.
</p>
