# National Employment Verification Network (NEVN)

A decentralized system for fraud-free employment verification using blockchain technology.

## 📌 Project Overview
The National Employment Verification Network (NEVN) aims to prevent employment fraud by providing a tamper-proof and transparent mechanism to verify employers and job offer letters. The system uses **Hyperledger Fabric** to store immutable verification records while keeping large data off-chain for scalability.

## 🎯 Objectives
- Verify employer authenticity through a trusted authority
- Prevent fake and forged offer letters
- Enable instant verification for candidates
- Maintain an immutable audit trail using blockchain

## 🏗️ System Architecture
- **Frontend**: Employer, Authority, and Candidate portals
- **Backend**: Node.js & Express API Gateway
- **Blockchain**: Hyperledger Fabric (permissioned network)
- **Database**: PostgreSQL (off-chain storage)
- **Deployment**: Docker & Docker Compose

## 🧰 Tech Stack
- Backend: Node.js, Express.js
- Blockchain: Hyperledger Fabric
- Database: PostgreSQL
- Frontend: React
- Tools: Docker, GitHub
